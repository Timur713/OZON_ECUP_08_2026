# Ключ чтения кривой остатков — ЗАФИКСИРОВАН ДО РЕЗУЛЬТАТА

Исторический pre-registration artifact; пересмотру задним числом не подлежит,
но **не является текущим decision protocol**. Первоначальная реализация не была
полностью pair-safe, а pair-level uncertainty оказалась выше этой грубой оценки.
Текущие controls и gates заморожены в разделе pair-safe файла
`../RESEARCH_PROTOCOLS.md`; корректный вывод старого аудита — только отсутствие
крупного безусловного повторяемого residual signal, не «доказанный потолок».

## Три числа рядом с кривой
1. **Шумовой пол инструмента.** SE корреляции на 250k = 1/sqrt(250000) = 0.0020.
   Для g=30 усреднение по 8 парам (зависимым) снижает его до ~0.001-0.0015.
   Ниже этого не читается в принципе.
2. **Смещение «облегчённый бустинг вместо стека».**
   стек 1.6468181 -> R2 = 0.49463 | лучший одиночный бустинг 1.651367 -> R2 = 0.49177
   разница = 0.00286. В кривой стоит ЕЩЁ более слабая модель (300 итераций, 30%
   юзеров, hurdle без блендинга), так что смещение может быть больше 0.003.
   Это и есть «уже взятая стеком структура», которую кривая покажет как остаточную.
3. **Перевод в RMSLE.** sqrt(V(1-rho)) ~ sqrt(V)(1-rho/2) => выигрыш = R*rho_r/2 = 0.82*rho_r
   rho_r=0.002 -> 0.0016   rho_r=0.01 -> 0.008   rho_r=0.05 -> 0.041

## РЕШАЮЩЕЕ ПРАВИЛО
* **|corr| < 0.01 на всех g** — с учётом пола и смещения это НОЛЬ.
  Практический потолок подтверждён. Полный разворот на репозиторий и защиту.
  Кривая идёт финальным аргументом главы: оракул 0.593 + нулевые остатки.
* **Плоский положительный уровень >= 0.01** — упущена устойчивая структура.
  Действие: признаки долгого горизонта и регулярности, триаж одним сабмитом.
* **Затухающая часть >= 0.01** — фаза читаема и недобрана.
  Действие: короткие окна, мультизадачные горизонты. Тогда нужна калмановская граница.

## ЧЕГО КРИВАЯ НЕ МОЖЕТ (зафиксировать заранее)
Разрыв до лидера 0.0016 отвечает rho_r = 2*0.0016/1.647 = 0.0019 — РОВНО пол инструмента.
Кривая не увидит преимущество лидера ни при каком исходе.
Корректная формулировка при нулевой кривой:
  "пулов масштаба >= 0.008 нет"
НЕ "лидер не знает ничего, чего не знаем мы".
